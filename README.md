
# Lumiere Living - Modern Furniture Landing Page

Welcome to **Lumiere Living**, an exquisite, modern, and high-performance landing page designed for a premium furniture brand. This project showcases the intersection of luxury design and cutting-edge web technology.

## 🌟 Key Features

### 1. Immersive User Experience
- **Fluid Animations**: Leveraging modern CSS transitions and React-specific animation patterns to create a seamless scroll and hover experience.
- **Responsive Mastery**: Fully optimized for mobile, tablet, and ultra-wide desktops using Tailwind's mobile-first breakpoints.
- **Glassmorphism UI**: High-end navbar and UI components utilizing backdrop-blur effects for a premium feel.

### 2. AI-Powered Concierge (Gemini Integration)
- **Design Assistant**: A floating chat assistant powered by **Google Gemini 1.5 Flash**.
- **Context-Aware**: The AI understands the furniture brand's identity and provides tailored interior design advice to users.
- **Concise Logic**: Built to keep users engaged with smart, brief, and professional responses.

### 3. Extensive Functionality
- **Dynamic Collections**: Filterable product grid that responds instantly to user category selections.
- **Rich Footer**: A robust footer section featuring deep-link navigation, social integration, newsletter subscription, and detailed contact information.
- **Performance Optimized**: Lazy loading of images and optimized component structure ensure lighthouse-ready performance.

## 🛠️ Tech Stack

- **React 18+**: For a component-based reactive UI.
- **TypeScript**: Ensuring robust type safety across the application.
- **Tailwind CSS**: Utility-first styling for lightning-fast UI development and consistent design tokens.
- **Google Gemini API**: Providing a "brain" to the landing page via `@google/genai`.
- **Lucide React**: A beautiful, consistent icon set.
- **Framer Motion Patterns**: (Implicitly modeled via Tailwind animations) for scroll and state transitions.

## 📂 Project Structure

- `/components`: Modular UI blocks (Hero, Navbar, Footer, etc.).
- `/services`: API integration logic, specifically for Gemini.
- `/constants`: Centralized mock data and configuration.
- `App.tsx`: The heart of the single-page application orchestrating the layout.

## 🎨 Design Philosophy

**Lumiere Living** follows a "Quiet Luxury" aesthetic. 
- **Typography**: A contrast between the sophisticated **Playfair Display** (serif) for headings and the clean **Inter** (sans-serif) for body text.
- **Color Palette**: Dominated by stone, charcoal, and white to allow high-quality furniture imagery to take center stage.
- **Spacing**: Generous white space to give the design "room to breathe," reflecting the luxury of the products.
